## House rules

- One well-scoped change per commit; commit and push after every change.
- Commit as `Agha Moutsim <131957706+agha-moutsim@users.noreply.github.com>`.
- Never fabricate a price, fee, margin or count. Absent stays `None`, and a refusal carries
  a sentence. Read `CONSTRAINTS.md` before touching money or verdict logic.
- The work is scoped to the ten planned features, not the whole product.
- Never write credentials into the repo or a command line. Git pushes authenticate through
  `gh` (keyring). If a key was exposed, rotate it - do not reuse it.

## Checks before pushing

From the repo root: `python -m pytest tests/ -q` (~3 min).
From `frontend/`: `npm run typecheck`, `npx vitest run`, `npm run build`.

The pre-commit hook already runs prettier, typecheck and the backend suite; a failed hook
leaves no commit, so check `git log --oneline -1` after committing.

## Frontend
